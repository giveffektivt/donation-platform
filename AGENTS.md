# db migrations:

- Do not edit the db/schema.sql, it's autogenerated by `dbmate migrate`
- Create db migration files using `dbmate new` command, like `dbmate new rename-a-vitamin-cause`
- `99999999999999_views.sql` is special and is continuously reapplied, change it directly instead of via new migrations.
- Do not fill in the `-- migrate:down` portion of the generated db migration file.
- Apply db migrations using `dbmate migrate && dbmate rollback && dbmate migrate` to run all migrations and reapply `99999999999999_views.sql`.
